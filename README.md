# Python Expense Tracker

A simple expense tracking application built using Python.

## Features
- Add daily expenses
- Track spending
- View expense records
- Organize expenses

## Technologies Used
- Python

## How to Run

1. Install Python.
2. Clone this repository.
3. Run the following command:

```bash
python expense_tracker.py
```
